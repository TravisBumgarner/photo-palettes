# About

Takes screenshots of seis-colores and crops them to a square.

1. `python -m venv venv`
1. `source venv/bin/activate`
1. `pip install -r requirements.txt`
1. Load up `seis-colores` on the `for-social-media` branch
1. Take screenshots on second monitor at full screen. 
1. Run `python-resize.py`.
1. Ship photos to social media.
