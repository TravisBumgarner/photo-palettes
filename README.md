Photo Palettes

Social platform for generating color palettes from photos.

# Local Setup

`make bootstrap` - Follow all instructions output to terminal.

On network changes you'll need to run `make set-ip`.

# Deploy to Prod

make deploy-all

# Heroku Stuff

Connect shell to Heroku - `heroku ps:exec --app photo-palettes-backend`
Logs - `heroku logs --tail --app photo-palettes-backend`
